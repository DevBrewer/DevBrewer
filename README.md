### 📂 Projects & Studies

#### 🚀 [learn-gpu](https://github.com/DevBrewer/learn-gpu)
*A hands-on exploration of modern GPU programming and real-time 3D graphics in Rust.*

Following along with the popular [Learn Wgpu](https://sotrh.github.io/learn-wgpu/) series, customized with a modular `framework` crate and [`glam`](https://crates.io/crates/glam) for 3D math:

- **Key Highlights**:
  - Incremental chapters: Windowing, custom WGSL shaders, vertex/index buffers, and texture mapping.
  - 3D cameras, uniform buffers, and hardware instancing with quaternions.
  - Multi-material 3D model loading (GLTF / OBJ).
  - Real-time Blinn-Phong lighting pass with dynamic orbiting point lights.

#### 🦀 [nature-of-code-macroquad](https://github.com/DevBrewer/nature-of-code-macroquad)
*An open-source study repository porting Daniel Shiffman's classic book to Rust.*

Following along with Daniel Shiffman's [*The Nature of Code*](https://natureofcode.com/) using the [Macroquad](https://macroquad.rs/) engine. All credit for the teaching, math concepts, and exercises belongs to Daniel Shiffman.

- **Topics covered**: Vectors, Newton's laws (friction, drag, gravity), harmonic oscillations, spring lattices, and chaotic double pendulums.
